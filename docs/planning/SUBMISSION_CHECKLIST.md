# Future submission and testing checklist

No submission is being prepared as a completed solution now. Review official guides announced for November 13; video length, field limits, hosting, judging rubric and other exact requirements remain unverified.

- [ ] Full challenge and applicable local/global requirements re-read; traceability recorded.
- [ ] Same-event eligible team, max six; correct challenge/team/project page.
- [ ] Authorized build time, owner phrase, baseline commit and prepared-artifact ruling recorded.
- [ ] Genuine source IDs, UTC times, product versions, units, quality and exact AOI cited.
- [ ] Scientific outputs reproducible; original files preserved; invalid-data handling explicit.
- [ ] Physical registration/radiometry/reference evidence assessed; uncertainty disclosed.
- [ ] Appropriate evaluation completed, or unsupported accuracy/flood claims omitted.
- [ ] Normal operation, missing files/metadata, empty/invalid regions and failure messages tested during event.
- [ ] Display previews separated from scientific values; labels/legends/dates/CRS correct.
- [ ] Cold-start instructions and offline demonstration rehearsed by another member if available.
- [ ] All third-party sources/licenses/attribution reviewed; original content rights confirmed.
- [ ] AI assistance and its use disclosed as FAQ requires; generated claims manually verified.
- [ ] No secrets, private personal data, unnecessary imagery or disallowed prepared code published.
- [ ] Required project fields/assets/links satisfy then-current guide; link access tested.
- [ ] Final commit and submission receipt retained before confirmed deadline with buffer.
